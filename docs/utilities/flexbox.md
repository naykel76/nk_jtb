# Flexbox

<p class="lead">Utilities for controlling flex containers and how their items size, order, and wrap.</p>

## Flex Shrink

| Class | CSS              | Description               |
| ----- | ---------------- | ------------------------- |
| `fs0` | `flex-shrink: 0` | Prevent shrinking         |
| `fs1` | `flex-shrink: 1` | Allow shrinking — default |

## Flex Grow

| Class | CSS            | Description               |
| ----- | -------------- | ------------------------- |
| `fg0` | `flex-grow: 0` | Prevent growing — default |
| `fg1` | `flex-grow: 1` | Fill available space      |
